# Product 3D models

Add an optimized GLB file named exactly after the product slug to enable the interactive 3D and AR viewer. For example:

`public/models/thac-nuoc-gom-men-soi.glb`

The product API detects the file automatically. Keep GLB files compressed and reasonably sized for mobile connections. AR requires a supported browser and device; iOS Quick Look may also need a USDZ model to be supplied separately.
